# Visor: descargas

Instaladores de **Visor**, lector universal de documentos para Windows (PDF, Word, PowerPoint, Excel, CSV,
Markdown, JSON, draw.io e imágenes, con pestañas).

Este repositorio solo contiene los instaladores, publicados en [Releases](../../releases). El código no está aquí.

- **Instalar:** descarga el último `Visor-Setup-<versión>.exe` de Releases y ejecútalo.
- **Actualizar:** Visor se actualiza solo; descarga la versión nueva en segundo plano y la instala al cerrarlo.
- **Verificación:** cada release indica el SHA-256 del instalador; Visor lo comprueba antes de instalar.
- **Privacidad:** Visor envía un identificador aleatorio de instalación, su versión y recuentos de tipos de
  archivo y funciones usadas. Nunca nombres, rutas ni contenido de archivos. Se puede desactivar en Inicio → Ajustes.
